What is the difference between a process and a thread, and when would you use each?
✦ Claude answer
A process is an isolated program with its own memory space. A thread is a unit of execution within a process, sharing memory with other threads in the same process.

Use threads when tasks need to share data cheaply (e.g. a web server handling concurrent requests). Use separate processes when isolation matters (e.g. browser tabs, microservices).

How it works

A production-ready desktop AI workflow.

ZeroLagAI runs as a native desktop application on your own machine. Configure audio, optional knowledge files, and Claude API access once, then use the same setup across all your practice and coaching sessions.

1

Start the app and set your context

Launch ZeroLagAI before a practice or coaching session. Optionally load a Markdown reference file with your preparation material. Configure system audio once using BlackHole on Mac or Stereo Mix on Windows.

optional: load any .md prep file
one-time audio routing setup
inference: Claude API or Azure OpenAI
2

Feed it the question any way you need

Voice detection runs automatically. For anything visual on screen, press ⌘S to enter capture mode, then select the region you want. You can take multiple screenshots in one go: a diagram, then a code block, then a schema. When you are done selecting, click Ask and all of them get analyzed together. For anything you want to type yourself, one shortcut opens the manual input.

auto speech detection, no trigger needed
⌘S capture mode, select any region, multi-shot
click Ask when done to submit all screenshots
⌘Enter to type a question manually
3

Claude streams focused, context-aware guidance into the desktop overlay

The assembled context, your question, your notes, and optional screenshots, is sent to Claude via the Anthropic API. Claude generates structured, role-specific coaching responses that stream word by word into a lightweight desktop overlay. The first word appears in about a second. Your entire prep file and session history are included in every Claude API call, so every answer is grounded in your own preparation material.
